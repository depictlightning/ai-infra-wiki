# Unlimited OCR 2：稀疏视觉参考与分块长文档解析（技术报告，2026）

> **原题**：Unlimited OCR Works 2
>
> **副题**：Pioneering the OCR-3.0 Era: From Long- to Unlimited-Horizon Parsing

> **一句话总结**：Unlimited OCR 2 以当前页为范围筛选视觉块，再以重叠页面分块和 KV 复用控制显存；在作者构造的 103–300 页 MarathonDocBench 上总分为 77.06，分块使峰值 KV cache 从 47.00 GB 降到 1.77 GB，但文档级全局信息仍可能丢失（表 2、表 4、§6）。[^report]

**版本与作者**：本页依据百度文心团队 2026 年 10 月发布的 15 页技术报告及其官方仓库。报告首页署名 Baidu ERNIE Team，末尾列出核心贡献者 Shu Wei、Jingjing Wu、Qunyi Xie 等；报告没有给出新版的 arXiv 编号。官方仓库中的 2026 年 6 月 arXiv:2606.23050 是一代 Unlimited OCR 的报告，不能当作本篇的编号。[^report][^repo]

## 问题与动机

多页文档解析需要同时处理页面文字、图表、阅读顺序与跨页表格。上一代 Unlimited OCR 使用参考滑动窗口注意力（R-SWA）限制文本历史，但解码时仍访问全部页面的视觉 token。文档页数增加后，单步注意力需要检查更多视觉信息；即使每次只输出一个 token，这部分成本也会增长（§1、§3.1）。[^report]

作者把问题拆成两层：**每一步实际读取多少视觉 token**，以及**多少页面的视觉 KV 真正保留在 GPU 中**。前者由稀疏参考滑动窗口注意力（SR-SWA）限制，后者由重叠分块、边界页 KV 复用和旧块释放控制。两者共同支撑百页处理；仅限制注意力读取范围，并不会自动释放全部页面的 KV（§3.3–3.4、图 4）。[^report]

## 关键观察 / 隐含假设

- **页面局部性**：作者假设转录当前位置时，当前页及附近内容提供了大部分必要视觉证据。Page Gate 据此把候选视觉块限制在目标页；一个块可能跨越相邻页。这个假设适合按页顺序解析，但跨越很远页面的引用和文档级标题层级可能需要已释放的信息（§3.3.1、§6）。[^report]
- **稀疏读取不等于稀疏驻留**：如果一次预填充全部页面，未被当前 query 选中的视觉 KV 仍可能留在 GPU；表 4 因而单独比较是否分块。假设固定块大小、固定文本尾部与有限每页视觉 token，分块后活跃 KV 随总页数增长的压力才能保持有界（§3.4）。[^report]
- **路由选择可以从解析损失学习**：Token Sieve 把选中块的路由概率变成注意力偏置，作者据此让解析目标的梯度传到路由器，无须额外的 KL 蒸馏损失。离散 TopK 仍会截断候选，选错块可能丢失文字或表格证据；报告没有单独给出路由召回率消融（§3.3.2）。[^report]

## 核心方法

**模型底座与训练**：模型沿用前代的 DeepEncoder 和 MoE 解码器，正文称总参数约 3B、每 token 激活约 0.5B；图 3 标为 A570M，报告没有解释这两处标注的差别。它从一代 checkpoint 出发，在 200 万多页和 1000 万单页文档上做一轮后训练，冻结视觉编码器与连接层，训练解码器。训练配置为 25 台、每台 8 张 H800，最大序列长度 64K；这是训练配置，不能据此推断推理实验使用相同硬件（§3.2、§4）。[^report]

**Page Gate：先确定可看的页面**。对当前输出 query，Page Gate 用与该 query 关联的页号筛选视觉块，仅保留与目标页相交的候选块。由于块边界和页边界不一定重合，候选块可以含有相邻页 token。位置编码将页级坐标交替设为 0、1，并与页内位置组合；这限制了页级位置编号的增长，但也使页号本身不足以唯一表达任意两页的全局距离（式 2–3）。[^report]

**Token Sieve：再选择固定预算的块**。路由器用每个候选块的紧凑 key 表示与当前 query 计算相关性，经 α-entmax 得到稀疏分布并取 TopK。选中块的对数概率做均值中心化后，加到相应 token 的注意力 logits；局部窗口内 token 仍走普通注意力。最终注意力集合是局部窗口与选中的远端块之并集（式 4–7）。官方 README 以 512 个工作参考 token 为例；这只是说明预算可以固定，不应当作报告所有实验的已核实配置。[^report][^repo]

**重叠分块与 KV 交接**。超长文档按页面切成多个重叠块；相邻块共享一个边界页。系统复用该页的视觉 KV 和上一块末尾的文本 KV，并释放不再活跃的页面缓存，然后继续解码下一块。算法 1 只在第一块加入指令。论文把这套分块运行方式与 SGLang 集成，面向一个长文档任务连续产出内容；它并不要求全部页面同时驻留在 GPU（算法 1、图 4、§4.2）。[^report]

## 设计取舍

- **固定读取预算换全局视野**：当前页筛选和 TopK 减少每步需要读取的视觉块，但远处页面的证据可能已经被过滤或释放。作者也承认当前机制没有保留完整文档级信息，标题层级是已知弱项（§6）。[^report]
- **重叠一页换缓存容量**：边界页和文本尾部为相邻块提供连续性；跨越多个块的表格、章节或引用是否足够，仅凭一页重叠不能保证。报告没有给出不同块大小、重叠页数和文本尾长的消融。
- **单步有界不代表总工作量不变**：固定窗口和参考预算约束单个 query 的注意力访问；随着总页数增加，图像编码、页面读取、输出 token 和最终结果存储仍要随文档规模增长。候选页的分块数量也会影响路由成本。

## 实验与结果

- **基准**：MPDocBench 覆盖最多 30 页；作者新建的 MarathonDocBench 有 100 份、每份 103–300 页的文档，约 20.5 万个布局元素。结构标注由逐页解析器初始化并由人工修订；文本转录经 VLM 迭代校验，标记出的分歧再由人工裁决（§3.1.2、§5.1）。[^report]
- **多页质量**：MPDocBench 总分为 84.59，比较的 Qwen3.8-Max 为 78.30、一代 Unlimited OCR 为 61.89。MarathonDocBench 上新版为 77.06，表中 Kimi-K3 为 33.74；一代因 40 页输入限制没有进入该基准。跨模型输入设置和可处理页数不同，不能把这一差距单独归因于 SR-SWA（表 1–2）。[^report]
- **单页质量**：OmniDocBench v1.6 上新版总分为 94.02，一代为 93.92；同表中的 OvisOCR2 为 96.47、TeleOCR 为 96.91。新版在这里略高于前代，并非该表中的最高分（表 3）。[^report]
- **缓存与吞吐**：MarathonDocBench 的分块实验中，单序列 `B=1` 的峰值 **KV cache** 为 1.77 GB，对照标准解码为 47.00 GB，约减少 26.6 倍；另在 `B=16` 下，端到端吞吐从 360 增至 1,315 TPS，约为 3.65 倍。这是不同并发度下的两项测量，不代表总显存减少 26.6 倍（表 4、§5.3.1）。[^report]
- **单步延迟**：图 6 的实验使用 Gundam 模式、`B=3`、每页固定生成 1,024 token；在 100 页处，SR-SWA 单步相对完整注意力和 R-SWA 分别为 7.0 倍、5.6 倍加速。图中的延迟曲线只覆盖到 100 页；报告没有据此证明任意长度下端到端时间恒定（图 6、§5.3.3）。[^report]

## 批判性分析

**“无限”对应的是哪项资源**：论文将固定大小的注意力参考集合与分块驻留结合，目标是使活跃 GPU KV 容量和单步注意力访问量不随总页数线性增加。报告测到的是 100 页处的单步性能与 103–300 页基准质量；总编码、生成和 I/O 时间不可能由此推出恒定。固定参考预算还依赖页面分辨率、候选块数、实际实现和并发条件。

**页面选择与跨页结构之间有张力**：式 2 的候选集合与 query 对应页相交，并非对整个历史文档的自由检索。分块后更早页面的视觉 KV 会释放，因此目录指向数十页前的标题、跨多个块延伸的表格或回指脚注都值得专门测试。论文报告的跨页文本和表格分数说明所测数据中存在可处理的跨页结构，不能证明任意距离的引用都被保留。可按引用距离和块边界位置分桶，测遗漏率及结构恢复率。

**消融与复现证据仍不足**：报告没有将 Page Gate、Token Sieve、路由偏置、重叠页复用及训练数据变化逐项拆开，也没有完整给出图 6 和表 4 的推理 GPU、分块参数或样本分布。新模型还做了一轮大规模后训练，因此与一代的质量差异不能完全归因于新注意力机制。建议固定模型、数据和硬件，分别关闭各模块，并报告路由与视觉预填充开销。

**比较基准要看输入条件**：MarathonDocBench 的标注结合自动解析、VLM 校验与人工修订；误差模式及未被标记的分歧仍可能影响分数。闭源模型与专用 OCR 模型的提示词、图像处理、输出长度上限和失败样本处理会影响比较。表 3 的单页结果也说明长文档领先不等于所有 OCR 指标都领先。

## 局限与后续工作

- 固定 GPU、图像分辨率与并发，分别测量图像预填充、路由、稀疏注意力、跨块重叠和输出阶段；同时报告总显存、端到端时延、吞吐与失败率。
- 改变块大小、重叠页数和文本尾长，按跨页距离统计表格、标题和脚注恢复质量，并设置跨多块引用的测试集。
- 比较固定预算下的块选择召回率和正文错误类型；加入全局摘要或可检索外部记忆，测量其质量收益与额外开销。
